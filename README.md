其次，我们需要打开注册网站或者应用的官方网站，找到注册入口。填写个人信息，包括姓名、性别、生日等。在填写手机号或者邮箱的时候，需要注意填写海外的手机号或者邮箱，并且要确保填写的信息是真实有效的。
